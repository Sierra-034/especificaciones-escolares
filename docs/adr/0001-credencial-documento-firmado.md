# ADR-0001 · La credencial es un documento firmado

- **Estado:** aceptada
- **Fecha:** por migrar
- **Fuente:** [Diseño del MVP](https://claude.ai/artifact/8z2qFXRnnrty1u4cJAGH4R)

## Decisión
La credencial es un documento firmado (JWS con EdDSA) con un id opaco, el plantel y la vigencia. El medio en que se muestra es aparte: teléfono ahora; papel o NFC después, sin cambiar el escáner.

Por migrar desde la fuente.
