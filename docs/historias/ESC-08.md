# ESC-08 · Plantillas oficiales con vigencia

Como **responsable administrativo**, quiero **definir la plantilla oficial de cada constancia con su vigencia**, para **que todas salgan iguales y con el formato vigente**.

## Criterios de aceptación

- Se edita sin programar.
- Cada cambio crea una versión nueva, y cada constancia guarda con qué versión se emitió.
- Una plantilla vencida no se puede usar.
- Cada plantilla dice qué datos lleva y si requiere revisión antes de emitirse.

## Pruebas de conformidad
