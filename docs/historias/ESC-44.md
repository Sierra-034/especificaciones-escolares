# ESC-44 · Importar el padrón

Como **control escolar**, quiero **importar el padrón desde el archivo que ya tenemos**, para **no capturar a nadie dos veces**.

## Criterios de aceptación

- Acepta el archivo actual sin recaptura.
- El padrón de la escuela sigue siendo la fuente de verdad.
- Los nombres con acentos se guardan en una sola forma (NFC).
