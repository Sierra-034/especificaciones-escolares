# ESC-46 · Revocar una credencial

Como **control escolar**, quiero **revocar una credencial perdida o de un alumno dado de baja**, para **que deje de ser válida**.

## Criterios de aceptación

- La revocación llega a las puertas en la siguiente sincronización.
- Una credencial revocada se marca como tal al escanearla, y solo advierte.
