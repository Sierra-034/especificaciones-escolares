# ESC-47 · Registrar o dar de baja un teléfono de puerta

Como **responsable del sistema**, quiero **registrar o dar de baja un teléfono de la puerta**, para **que solo los dispositivos autorizados registren entradas**.

## Criterios de aceptación

- Cada teléfono queda ligado a un punto de acceso.
- Un teléfono dado de baja ya no puede enviar hechos.
- El teléfono envía un latido periódico.
