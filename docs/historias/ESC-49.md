# ESC-49 · Solicitar el expediente de un alumno que viene de otra escuela

Como control escolar de la escuela destino, quiero solicitar el expediente de un alumno que viene de otra escuela, para inscribirlo sin pedirle papeles impresos.

## Criterios de aceptación

- Por definir: se escriben cuando se seleccione un paquete que la incluya.
- Comunes a todo el subsistema: consentimiento explícito del alumno o tutor cuando hay datos personales, solo los datos necesarios, y registro de quién envió qué, a quién y cuándo.

## Pruebas de conformidad

- Ninguna todavía.
