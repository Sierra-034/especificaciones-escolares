# ESC-54 · Autenticidad de un documento de otra escuela

Como **control escolar**, quiero **saber si un documento que me llega de otra escuela es auténtico**, para **evitar documentos falsos**.

## Criterios de aceptación

- Verifica la firma con la llave pública de la escuela emisora, tomada del directorio común.
- La otra escuela no necesita usar el mismo sistema, solo la misma especificación.

## Pruebas de conformidad

- Ninguna todavía.
