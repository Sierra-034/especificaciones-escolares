# ESC-61 · Identificarse con un código, sin contraseña

Como **alumno o persona del personal**, quiero **entrar a la plataforma con un código que llega a mi correo o teléfono registrado**, para **hacer trámites sin crear ni recordar una contraseña**.

## Criterios de aceptación

- Solo entra quien está en el padrón.
- El código llega al contacto que la escuela tiene registrado; si no hay contacto, control escolar entrega un código de activación en persona.
- Cambiar el contacto registrado solo se hace en persona.
- Cada entrada queda anotada con quién y cuándo.

## Pruebas de conformidad
