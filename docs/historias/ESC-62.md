# ESC-62 · Anular una constancia

Como **control escolar**, quiero **anular una constancia emitida por error**, para **que deje de ser válida aunque ya esté impresa**.

## Criterios de aceptación

- Pide un motivo y queda anotada con quién y cuándo.
- La constancia no se borra.
- Al verificarla aparece como anulada.
